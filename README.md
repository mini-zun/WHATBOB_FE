# WHATBOB FE 🍚

> “오늘 뭐 먹지?”라는 고민을 줄여주는 음식 추천 서비스

WHATBOB은 간단한 주문서 질문을 통해 사용자의 취향을 파악하고, 비선호 음식과 이전 피드백을 반영해 메뉴를 추천합니다.

이 저장소는 Expo와 React Native로 개발하는 WHATBOB 프론트엔드입니다.

## 프로젝트 링크

- [서비스 바로가기](https://whatbobfe-app.vercel.app)

## 주요 기능

### 카카오 로그인

- 카카오 계정으로 로그인
- 로그인 요청의 `state` 검증
- 서비스 JWT 저장 및 인증 요청에 사용
- 인증 만료 시 로그인 화면으로 이동
- 현재 로그인 흐름은 웹 환경에서 지원

### 비선호 음식 설정

- 백엔드에서 알레르기 19종 목록 조회
- 음식 이름 검색 및 선택·해제
- 선택한 음식을 태그로 표시하고 제거
- 로그인 사용자의 기존 비선호 목록 조회 및 복원
- 설정 완료 시 최종 선택 목록 전체 저장
- 저장 중 중복 요청 방지 및 실패 안내

현재 선택 목록은 알레르기 19종을 사용합니다. 서버에 저장된 일반 비선호 키워드도 선택 태그로 복원합니다.

### 주문서 기반 메뉴 추천

- 서버에서 받은 질문과 선택지를 동적으로 표시
- ‘상관없어요 · 건너뛰기’ 처리
- 이전 질문 이동 및 답변 수정
- 실제 질문 개수에 따른 진행률 표시
- 답변 제출 후 추천 결과를 서버가 반환한 순서대로 표시
- 추천 수락 또는 다음 메뉴 확인
- 모든 추천을 거절하면 홈으로 이동
- 로딩·오류·재시도 및 중복 제출 방지

추천 요청에 로그인 토큰을 전달해 사용자별로 저장된 비선호 정보가 적용되도록 연결했습니다.

### 친구와 같이 고르기

- 방 생성 및 참여
- QR 코드 표시·스캔
- 참여자 목록 표시
- WebSocket 기반 방 정보 갱신
- 방 종료 안내 및 방장 퇴장 확인

각자 주문서를 작성한 뒤 공동 추천으로 이어지는 흐름은 개발 중입니다.

## 추천 처리 흐름

1. FE가 주문서 질문을 조회합니다.
2. 사용자가 질문별 답변을 선택합니다.
3. FE가 답변과 서비스 JWT를 BE에 전달합니다.
4. BE가 사용자별 제외 조건을 적용합니다.
5. BE가 답변 적합도, 최근 추천 이력, 피드백을 고려해 메뉴를 선택합니다.
6. FE가 추천 메뉴를 하나씩 표시하고 사용자 피드백을 전달합니다.

추천 점수 계산과 후보 필터링은 백엔드에서 처리합니다.

## 기술 스택

| 구분 | 기술 |
| --- | --- |
| 언어 | TypeScript |
| UI | React 19.2, React Native 0.86 |
| 개발 환경 | Expo SDK 57 |
| 라우팅 | Expo Router |
| 웹 지원 | React Native Web |
| 스타일 | React Native StyleSheet, 공통 색상·폰트 정의 |
| 이미지·폰트 | Expo Image, Expo Font |
| QR 코드 | react-native-qrcode-svg, Expo Camera |
| API 통신 | Fetch API |
| 실시간 통신 | WebSocket |
| 배포 | Vercel |

앱 소스와 실행 스크립트는 저장소의 `app` 디렉터리에 있습니다.

## 개발 및 검증 현황

비선호 조회·저장과 추천 요청의 인증 연결을 구현했습니다. 실제 서버에서 다음 흐름을 검증합니다.

- 비선호 저장 후 화면 재진입 시 선택 복원
- 비선호 전체 해제 및 재저장
- 저장된 제외 키워드의 추천 반영
- 추천 수락·거절 피드백 처리
- 작은 화면에서 버튼과 긴 문구 표시
- 친구방 참여자 갱신·재연결·방 종료 처리

음식 일러스트는 현재 앱 캐릭터를 사용하며, 추후 이미지 API와 연동할 예정입니다.
